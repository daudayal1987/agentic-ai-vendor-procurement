# AI-Powered Enterprise Document Intelligence & Decision Assistant

A learning and showcase project for implementing enterprise-grade
Agentic AI using LangChain, LangGraph, RAG, multi-agent orchestration,
memory, tool calling, HITL, reliability, observability, and AWS
serverless architecture.

## Primary Goal

This project is built for learning and technical demonstration,
not as a commercial SaaS product.

## Architecture Principle

Local-first and cloud-portable.

The system will first run locally using lightweight local
infrastructure and will later be deployable to AWS with minimal
changes to business and agent logic.
